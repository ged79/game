====================================
기울기 센서 테스트 - 서버 실행 방법
====================================

[1단계] Python 서버 실행
------------------------
1. PowerShell 열기
2. 아래 명령어 입력:

cd C:\work_station\game
python -m http.server 8000


[2단계] ngrok HTTPS 터널 실행
-----------------------------
1. 새 PowerShell 창 열기
2. 아래 명령어 입력:

ngrok http 8000

3. 화면에 나오는 "Forwarding" 줄의 https:// 주소 복사


[3단계] 아이폰에서 접속
-----------------------
1. Safari에서 복사한 https:// 주소 접속
2. "Visit Site" 클릭
3. "시작하기" 버튼 클릭
4. 권한 허용
5. 핸드폰 기울여서 테스트!


[서버 종료 방법]
----------------
각 PowerShell 창에서 Ctrl + C 누르기


====================================
파일 위치: C:\work_station\game\index.html
